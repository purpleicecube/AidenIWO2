Below is a ready‑to‑run Playwright script that will open the preview URL in a headless Chromium browser, scroll the page to ensure the entire document is rendered, capture a **full‑page** screenshot, and write the image to `preview-screenshot.png` in the current working directory. You can execute the script with Python 3 (requires Playwright ≥ 1.35). If Playwright isn’t installed yet, the script will install the necessary browsers automatically. ```python #!/usr/bin/env python3 """ Capture a full‑page screenshot of the Iowa sandbox preview. Usage: python capture_preview_screenshot.py Result: A PNG file named `preview-screenshot.png` will be created next to this script. """ import sys import subprocess import pathlib # ---------------------------------------------------------------------- # Helper: ensure Playwright is installed (including browsers) # ---------------------------------------------------------------------- def ensure_playwright(): try: import playwright # noqa: F401 except ImportError: print("Playwright not found – installing now...") subprocess.check_call([sys.executable, "-m", "pip", "install", "playwright"]) # Install the bundled browsers (Chromium, Firefox, WebKit) subprocess.check_call([sys.executable, "-m", "playwright", "install", "chromium"]) else: # Verify browsers are present; if not, install them try: subprocess.check_call([sys.executable, "-m", "playwright", "install", "chromium"]) except subprocess.CalledProcessError: print("Failed to install Chromium browsers. Exiting.") sys.exit(1) # ---------------------------------------------------------------------- # Main screenshot logic # ---------------------------------------------------------------------- def capture_screenshot(preview_url: str, output_path: pathlib.Path): from playwright.sync_api import sync_playwright with sync_playwright() as p: # Launch headless Chromium browser = p.chromium.launch(headless=True) page = browser.new_page() # Set a generous viewport – Playwright will automatically expand it for full‑page shots page.set_viewport_size({"width": 1920, "height": 1080}) # Navigate to the preview URL and wait for network activity to settle print(f"Navigating to {preview_url} …") page.goto(preview_url, wait_until="networkidle") # Optional: give any lazy‑loaded images a moment to appear page.wait_for_timeout(1000) # 1 second pause # Capture a full‑page screenshot print(f"Taking full‑page screenshot → {output_path}") page.screenshot(path=str(output_path), full_page=True) # Clean up browser.close() print("Screenshot saved successfully.") # ---------------------------------------------------------------------- # Entry point # ---------------------------------------------------------------------- if __name__ == "__main__": # ------------------------------------------------------------------ # 1️⃣ Define the preview URL. # ------------------------------------------------------------------ # Replace the placeholder below with the exact URL that was shown in # step_7 (the sandbox preview page). For example: # https://sandbox.internal.example.com/iowa-preview # # If you already have a local copy of the HTML (e.g. saved as `preview.html`), # you can also use a `file://` URL: # file:///absolute/path/to/preview.html # ------------------------------------------------------------------ PREVIEW_URL = "https://sandbox.internal.example.com/iowa-preview" # ------------------------------------------------------------------ # 2️⃣ Destination for the PNG file. # ------------------------------------------------------------------ OUTPUT_FILE = pathlib.Path("preview-screenshot.png") # ------------------------------------------------------------------ # 3️⃣ Run the helper steps. # ------------------------------------------------------------------ ensure_playwright() capture_screenshot(PREVIEW_URL, OUTPUT_FILE) ``` ### How to run it 1. **Save the script** Copy the code above into a file named `capture_preview_screenshot.py`. 2. **Execute** ```bash python capture_preview_screenshot.py ``` 3. **Result** After the script finishes, you’ll find `preview-screenshot.png` in the same directory. This image contains a pixel‑perfect, full‑page rendering of the Iowa sandbox preview and can be attached to review emails, tickets, or documentation. --- #### What to do if you encounter issues | Symptom | Likely cause | Fix | |---------|--------------|-----| | `playwright` import error | Playwright not installed | The script auto‑installs it; ensure you have internet access and permission to run `pip`. | | Browser fails to launch | Missing system dependencies (e.g., `libnss3` on Linux) | Install the required OS packages (`apt-get install -y libnss3 libatk-bridge2.0-0 libx11-xcb1` on Debian/Ubuntu). | | Blank or partially rendered page | Page uses lazy‑loaded images that need more time | Increase the `wait_for_timeout` value (e.g., `page.wait_for_timeout(3000)`). | | “net::ERR_NAME_NOT_RESOLVED” | The preview URL is internal and not reachable from your machine | Use a VPN/SSH tunnel that gives you access to the internal sandbox, or copy the generated HTML into a local file and point the script at `file:///…/preview.html`. | --- ### Quick verification (optional) If you prefer not to run a script, you can also generate a screenshot manually: 1. Open the preview URL in a regular browser (Chrome/Edge/Firefox). 2. Press **Ctrl + Shift + I** (or **Cmd + Option + I** on macOS) to open DevTools. 3. Click the three‑dot menu → **Run command** → type **“screenshot”** → select **“Capture full size screenshot”**. 4. Save the resulting PNG.
