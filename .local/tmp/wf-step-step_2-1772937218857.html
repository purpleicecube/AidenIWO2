Publishing Instructions

To publish the site to a live web host, follow these steps:

  • Upload all HTML files (home.html, features.html, pricing.html, about.html, contact.html) to the root directory of your web server.
  • Ensure the file index.html points to home.html (or rename home.html to index.html).
  • Set the MIME type for .html files to text/html on the server (most hosts do this by default).
  • If you use a CDN or static‑site host (e.g., Netlify, Vercel, GitHub Pages), simply push the files to the repository or configure the deployment folder.
  • Test the live URL to confirm navigation, images, and the contact form work as expected.
