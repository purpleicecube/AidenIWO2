    Iowa Site Preview – Sandbox Rendering

    Detected Rendering / Security Issues

    • Missing Content‑Security‑Policy meta tag – the assembled page does not enforce a CSP.
    • External hero images are loaded from https://picsum.photos. If a CSP restricting img-src to self or data: is added later, these images will be blocked.
    • Hash‑based navigation (#home, #about, etc.) works in a normal browser but may require the iframe to allow URL fragment changes; most browsers support this, but it’s worth confirming.
    • No JavaScript is used, so the site is fully functional without scripts, which aligns with the security review.
