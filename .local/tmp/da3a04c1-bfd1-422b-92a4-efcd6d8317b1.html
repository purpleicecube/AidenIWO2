Project Overview

This document outlines the structure, key sections, placeholder copy, and navigation map for the Iowa website. It is intended for Mark (design & development) and Nyx (security).

Pages & Sections

Home

  • Hero Section – “Welcome to Iowa – Seamless Solutions for Modern Teams”
  • Key Benefits – three columns with placeholder copy.
  • Featured Screenshot – placeholder image.
  • Call‑to‑Action – button “Get Started”.

About

  • Company Story – placeholder paragraph.
  • Mission & Vision – two short statements.
  • Team Grid – placeholder images (picsum).
  • Values – list of four values.

Features

  • Feature Overview – intro paragraph.
  • Individual Feature Blocks – six blocks, each with icon placeholder and copy.
  • Comparison Table – placeholder table markup.

Pricing

  • Pricing Tiers – three cards (Starter, Pro, Enterprise) with placeholder pricing.
  • Feature Checklist – bullet list per tier.
  • FAQ – three common questions.

Contact

  • Contact Form – fields: Name, Email, Message (placeholder labels).
  • Map Embed – placeholder image.
  • Support Info – phone, email, address.

Navigation Map

All pages share a top navigation bar linking to Home, About, Features, Pricing, Contact. The footer repeats these links plus privacy policy and terms.

Notes for Team Members

Mark – Design & Development

  • Implement responsive layout using flexbox/grid.
  • Use Apple‑style minimalism: ample white space, crisp typography.
  • Placeholder images from https://picsum.photos with appropriate dimensions.
  • Export final HTML/CSS as static files.

Nyx – Security

  • Review all generated HTML for XSS vectors.
  • Ensure form inputs are properly escaped and use CSP headers.
  • Validate that external image sources are loaded over HTTPS.
  • Provide a security checklist for the final build.
