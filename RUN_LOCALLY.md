# Running AIDEN_IWO Locally

## Prerequisites

| Software | Version | Notes |
|---|---|---|
| Node.js | v20+ | Currently developed on v20.20.0 |
| npm | v10+ | Currently developed on v10.8.2 |
| PostgreSQL | 14+ | Any recent version should work |

## Environment Variables

Create a `.env` file in the project root (or export these in your shell):

| Variable | Purpose | Required? |
|---|---|---|
| `DATABASE_URL` | PostgreSQL connection string | **Yes** |
| `SESSION_SECRET` | Random string for encrypting session cookies | **Yes** |
| `OPENAI_API_KEY` | For sub-agents using OpenAI models | At least one LLM key required |
| `ANTHROPIC_API_KEY` | For sub-agents using Anthropic/Claude models | At least one LLM key required |
| `GROQ_API_KEY` | For sub-agents using Groq-hosted models | At least one LLM key required |
| `OPENROUTER_API_KEY` | For sub-agents using OpenRouter | At least one LLM key required |
| `SENDGRID_API_KEY` | For email notifications via SendGrid | Optional |
| `APP_URL` | Your app's public URL (defaults to hostname) | Optional |

Example `.env`:

```
DATABASE_URL=postgresql://username:password@localhost:5432/aiden_iwo
SESSION_SECRET=your-random-secret-string-here
OPENAI_API_KEY=sk-...
```

You need **at least one** LLM API key matching whichever provider(s) your Aiden settings and sub-agents are configured to use.

## Authentication

The app currently uses **Replit OpenID Connect** for authentication, which relies on Replit-specific environment variables (`REPL_ID`, `ISSUER_URL`). These only work inside Replit's environment.

To run locally, you would need to replace or adapt the authentication system in `server/replit_integrations/auth/replitAuth.ts` with a local alternative (e.g., username/password using passport-local, which is already listed as a dependency).

This is the biggest hurdle to running locally.

## Setup Steps

1. **Clone the repository:**
   ```bash
   git clone https://github.com/purpleicecube/Aiden_IWO.git
   cd Aiden_IWO
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Set up PostgreSQL:**
   - Create a new database (e.g., `aiden_iwo`)
   - Set the `DATABASE_URL` environment variable

4. **Set environment variables:**
   - Set `SESSION_SECRET` to any random string
   - Set at least one LLM API key

5. **Push the database schema:**
   ```bash
   npm run db:push
   ```

6. **Start the development server:**
   ```bash
   npm run dev
   ```

The app will be available at `http://localhost:5000`.

## Available Commands

| Command | What it does |
|---|---|
| `npm run dev` | Starts the dev server (Express backend + Vite frontend on port 5000) |
| `npm run build` | Builds for production (compiles frontend + bundles backend) |
| `npm run start` | Runs the production build (`NODE_ENV=production node dist/index.cjs`) |
| `npm run db:push` | Pushes the Drizzle schema to your PostgreSQL database |
| `npm run check` | Runs TypeScript type checking |

## Project Structure

```
server/          - Express backend (API routes, orchestration, LLM client, PocketFlow engine)
client/src/      - React frontend (pages, components, hooks)
shared/          - Shared types and database schema (Drizzle ORM)
migrations/      - Database migrations (auto-generated by Drizzle)
attached_assets/ - User-uploaded assets
```

## Key Dependencies

**Backend:**
- Express 5 (web server)
- Drizzle ORM + PostgreSQL (database)
- OpenAI SDK, Anthropic SDK (LLM providers)
- Passport (authentication)
- SendGrid (email, optional)

**Frontend:**
- React 18 + Vite 7 (build tooling)
- TanStack React Query (data fetching)
- Tailwind CSS + shadcn/ui (styling and components)
- Wouter (routing)
- Recharts (charts)
- Framer Motion (animations)
