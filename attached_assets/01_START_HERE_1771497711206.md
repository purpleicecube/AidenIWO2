# 01 - START HERE (Replit)

## Goal
Run and refine the AIDEN(TIB) MVP in Replit without breaking core architecture.

## What This App Is
A FastAPI app with:
- API backend
- simple HTML UI
- 2-tier orchestration using PocketFlow

## Setup
1. Open project root.
2. Install deps:
```bash
pip install -r WS014_P_PODE/02_Execution/requirements.txt
```
3. Start server:
```bash
cd WS014_P_PODE/02_Execution
uvicorn api.main:app --host 0.0.0.0 --port 8080
```

## Test URLs
- `http://localhost:8080/` (UI)
- `http://localhost:8080/docs` (API docs)
- `http://localhost:8080/health` (health)

## First Functional Checks
1. `GET /health` returns status ok.
2. `POST /work-orders/submit` works on:
- completed path
- blocked path (BDM marker)
3. UI can submit and show response.
